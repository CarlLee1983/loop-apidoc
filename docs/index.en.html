Before any agent reads source content, raw PDF/Word must be converted to supported text. Built-in preprocess handles PDF/DOCX, validates DOCX through a bounded fail-closed OOXML gate, and writes source-hash provenance. The exact converted bytes must still pass manifest-bound inspect-source-risk. The scan never rewrites a source or echoes a matched payload; assess-sources --source-risk embeds the verified audit, and assemble --source-quality revalidates its binding.

The DOCX ZIP/XML fallback design is adapted from MIT-licensed virgiliojr94/book-to-skill at pinned revision efda3b2212ce1b2c052126e85e14de40a32442e8. This project has no runtime dependency on it and does not inherit its EPUB/RTF/MOBI scope; loop-apidoc adds bounded validation, batch preflight, provenance, and fail-closed contracts. Protected documentation that an interactive browser can render may be imported offline with import-rendered-url. Versioned capture provenance binds the original/canonical URL, timestamp, method, local file, and SHA-256; only a verified coverage match suppresses that origin fetch. Source-quality rejects may also expose explicit, bounded required_source_refs without crawling them.

Claim-level semantic evidence links deterministic support relationships to exact fragments; optional v1 evidence[] references re-materialize and verify source identity, locator, digest, and claim path before a run exists. Prose without a parsed scalar can support only its one exact bound claim, while allowlisted, versioned OpenAPI derivations are recomputed by Core. See core/relationships.json in legacy-compatible shadow runs.

Core retains tested, pure GraphQL/AsyncAPI compiler seams, but exposes no CLI or run workflow for either format until a named downstream consumer supplies a real source set and acceptance contract.
