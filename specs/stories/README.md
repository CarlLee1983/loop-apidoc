# Stories

Create approved work under `specs/stories/<story-id>-<slug>/` from `_template/`.
`story.md` and `acceptance.md` define intent and acceptance; `task.md` is optional
progress metadata. Validate a Story with ForgeFlow v0.3.2 `scripts/story-check`,
then use repository-local `skills/story-development/SKILL.md` and finish with
`make verify`.
